# AutoList - システム運用マニュアル & トラブル対応手順書

本マニュアルは、eBay出品自動化システム（AutoList）を運用する管理者およびスタッフ向けの操作説明書です。

---

## 1. スタッフ向け操作マニュアル（Google Sheets）

スタッフは、主にGoogleスプレッドシート（出品管理表）のみを使用して作業を行います。Monodasや開発環境へのアクセスは不要です。

### 1-1. 新規出品データの追加
1. 「**出品管理表**」シートを開きます。
2. 新しい行に、以下の必須情報を入力します。
   - **管理ID_SKU**: 一意の管理コード（例: PKMN-101）を入力します。
   - **商品名_JP**: メルカリなどの仕入元の商品名をそのまま入力します。
   - **仕入URL**: メルカリ等の商品ページのURLを入力します。
   - **Category**: ドロップダウンから該当ジャンルを選択します（Pokemon Cards, Figures, Vintage plastic models, Vintage toys, RC related, Game related）。
   - **Brand**: メーカーやブランド名を入力します。
   - **Condition**: コンディション（New / Used）を入力します。
   - **出品価格_USD**: 出品したいドル価格を入力します。
   - **画像URLs**: 商品画像のURLをカンマ区切り、または改行区切りで入力します。
   - **担当者**: スタッフの名前を入力します。
3. **AI_Status** を「**pending_ai**」に設定します。

### 1-2. エラー発生時の対応手順
自動実行後、データに問題がある場合はスプレッドシート上で通知されます。

- **AI_Status が「ai_error」になった場合**
  - **原因**: OpenAI API接続エラー、または入力情報不足。
  - **対応**: 商品名_JPやその他の欄に十分な情報があるか確認し、再度「**pending_ai**」に戻してください。

- **Validation_Status がエラーになった場合**
  - **format_error**: 必須項目（画像やURLなど）の不足。不足項目を追加して「**pending_ai**」に戻します。
  - **vero_flagged**: eBayの禁止ワード（Replica, Fake等）が含まれています。警告箇所（商品名やAI生成されたタイトル等）を修正して「**pending_ai**」に戻します。
  - **duplicate_suspected**: 過去に出品されたアイテム（同一URL、JAN、型番、または類似画像）と重複しています。重複理由（Error_Field等）を確認し、出品不要であれば削除、問題なければ管理者に確認します。

## 2. 管理者向け運用フロー

管理者はシステムの起動、高額商品の確認、およびシステム監視を担当します。

### 2-1. デイリー実行手順
1. **Pythonプログラムの実行**
   コマンドプロンプトまたはPowerShellで以下を実行します。
   ```bash
   python main.py
   ```
   スプレッドシートから「pending_ai」行を検知し、AI生成、重複チェック、VeROチェックが自動で行われます。
2. **PAD（Power Automate Desktop）の実行**
   Pythonプログラム完了後、PADフローを起動してMonodasへの登録を行います。

### 2-2. 高額商品の確認と最終出品（Monodas）
- 出品価格が **300 USD** 以上の商品は、自動出品されず、安全のためMonodas上で「**下書き（Draft）**」として保存されます。
- 管理者はMonodasにログインし、下書きリストから高額商品の内容を確認し、問題なければ手動で「出品（Publish）」ボタンを押してください。

## 3. トラブル対応手順書（トラブルシューティング）

### 3-1. 接続エラー
- **Google Sheets APIに接続できない**
  - `credentials/service-account.json` が正しいか確認してください。
  - スプレッドシートID（`config/api_keys.json` に記載）が正しいか、サービスアカウントにスプレッドシートの「編集者」権限が付与されているか確認してください。
- **OpenAI APIエラー**
  - `config/api_keys.json` の `api_key` が有効で、利用枠（クレジット）が残っているか確認してください。

### 3-2. 自動診断ツールの実行
何か不具合が発生した場合は、最初に以下の診断プログラムを実行してください。
```bash
python diagnose_system.py
```
エラーの原因となっているライブラリ不足や設定ファイルの間違いが画面上にわかりやすく表示されます。
